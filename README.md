## The entry

> Prod broke because the 'quick hack, will fix later' I wrote in 2019 is now load-bearing, and later just arrived.

The joke turns the worn "quick hack, will fix later" excuse on its head: the hack survived so long it became load-bearing infrastructure, and "later" finally showed up.
